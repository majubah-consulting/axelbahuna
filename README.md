# Axel Bahuna — site vitrine artistique

Site statique, bilingue et responsive consacré au parcours et aux œuvres d’Axel Bahuna, artiste peintre installé à Saint-Désir près de Lisieux.

## Positionnement

- Site vitrine non marchand.
- Aucun prix, panier ou paiement en ligne.
- Les visiteurs peuvent découvrir les œuvres et préparer un e-mail de contact.
- Le numéro de téléphone personnel n’est pas publié.

## Lancer le site localement

Aucune dépendance n’est nécessaire.

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Avant la mise en ligne

1. Ajouter l’adresse postale de Majubah Consulting aux mentions légales lorsqu’elle sera confirmée.
2. Vérifier les titres, dates, dimensions et techniques des œuvres.
3. Vérifier l’autorisation de publication des photos où figurent des tiers.
4. Connecter le domaine `axelbahuna.fr` à GitHub Pages.

## Déploiement

Le projet est destiné à être publié avec GitHub Pages.
