# Brief d’exécution pour Codex

Le projet contient une première version complète du site d’Axel Bahuna. Ta mission est de la contrôler, l’exécuter et la préparer à être publiée dans le dépôt `majubah-consulting/axelbahuna`.

## Étapes demandées

1. Examiner `README.md` et `AGENTS.md`.
2. Lancer le site localement avec un serveur statique.
3. Vérifier l’affichage desktop, tablette et mobile.
4. Corriger les erreurs HTML, CSS ou JavaScript éventuelles.
5. Vérifier la galerie, les filtres, la lightbox, la navigation mobile et le basculement FR/EN.
6. Compresser davantage les images uniquement si la qualité des tableaux reste fidèle.
7. Créer une branche `codex/site-v1` et y déposer tous les fichiers.
8. Ouvrir une pull request vers `main` intitulée `Création du site vitrine Axel Bahuna`.
9. Dans la PR, lister clairement les éléments encore à confirmer : e-mail, mentions légales, dates, titres et autorisations de publication.

## Résultat attendu

Un site artistique, immersif, rapide et accessible, sans vente en ligne, prêt à être déployé sur `axelbahuna.fr`.
